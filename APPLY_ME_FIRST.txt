SC64 Majora's Mask Save-State Prototype v0.2 - CONTROLLER TRIGGER

Copy everything in this folder over the root of your existing
N64FlashcartMenu-SaveState repository and replace matching files.

Changes from v0.1:
- No physical SummerCart button is required.
- Trigger is read from Controller 1 during VI interrupts.
- Combo: L + R + Z + C-Up.
- First combo press saves, release combo, second combo press loads.
- An SC64-SDRAM latch prevents holding the combo from firing every frame.
- Fresh ROM boot explicitly invalidates old RAM-only state and input latch.

Still experimental:
- Majora's Mask only.
- Expansion Pak required.
- RAM-only state, lost/invalidated on a fresh boot.
- RCP state is incomplete, so load may crash or restore with graphics/audio issues.
